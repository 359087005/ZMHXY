# 窗口后台实时预览 & 自动化工具

在不激活窗口的前提下，实时预览目标程序画面，并支持后台自动化操作（点击等）。

## 环境要求

- Windows 10 / 11
- Python 3.10+
- 依赖：`opencv-python`

## 运行

```bash
pip install -r requirements.txt
python window_capture.py
```

> 如果目标是以管理员运行的游戏，需要以管理员身份运行 Python，否则 Windows UIPI 会阻止所有输入注入。

## 文件说明

| 文件 | 作用 |
|---|---|
| `window_capture.py` | 主程序 GUI，窗口预览、Debug 放大镜、脚本执行 |
| `script_action.py` | 自动化动作库，封装后台点击、拖动、按键、模板识别等能力 |
| `game_logic.py` | 当前“执行脚本”按钮的逻辑入口，按勾选功能块执行游戏内流程，热重载后直接执行 |

## 功能一览

### 权限处理
- 标题栏会显示当前是“普通权限”还是“管理员权限”
- 程序启动时会自动申请管理员权限，不再需要手动点击「管理员重启」
- 新增「管理员重启」按钮：通过 UAC 直接重启当前程序为管理员权限
- 源码运行时，自动管理员重启会优先使用 `pythonw.exe`，尽量避免额外弹出控制台窗口
- 当日志里出现 `err=5 / 拒绝访问` 时，优先处理权限问题，而不是继续切换窗口策略

### 智能锚定
- 下拉框仍显示 Alt+Tab 可见的标题窗口，便于选择
- 点击「锚定窗口」后，会自动扫描**同进程的所有顶层窗口**
- 如果当前选中的句柄只是标题壳窗口，会自动切换到同进程里更大的真实渲染/输入窗口
- 候选窗口列表、面积、类名、矩形信息都会写入日志面板

### 窗口实时预览
- 使用 **DWM Thumbnail API** (`DwmRegisterThumbnail`) 直接从 GPU 合成器获取画面
- 与 Windows 任务栏悬停预览使用相同机制，可观察 DWM 当前持有的合成画面
- 默认实时预览属于 **DWM/GPU 合成预览**
- 可切换显示完整窗口或仅客户区
- 注意：这里拿到的是 **DWM 当前缓存/合成的帧**，不是“强制游戏继续渲染”的能力
- 如果游戏在失焦、边缘停靠、完全遮挡后停止 `Present` 或降低帧率，预览也会跟着冻结或低频更新
- 主预览现在支持直接设置**主预览间隔（秒）**，填 `0` 表示继续实时显示 DWM/GPU 预览
- 当主预览间隔大于 `0` 时，程序会按设定节奏短暂挂载 `DWM thumbnail` 取一帧，再注销并显示静态快照，避免主预览持续高频刷新
- 新增「开启采样预览」按钮：主动调用 `PrintWindow` / 位图抓取刷新预览，不再只依赖 DWM 缩略图
- 采样预览属于 **PrintWindow / GDI 采样链路**，不是 GPU 合成预览
- 当“脚本生效但 DWM 预览静止”时，优先尝试采样预览模式
- 采样预览已做性能优化：更快的像素转换、更高刷新频率、失败自动快速重试
- 采样预览现在支持直接设置**采样间隔（秒）**，例如填 `1` 或 `2` 表示每 1 秒 / 2 秒采样一次
- 采样预览开启后修改间隔也会即时生效，不需要先停掉再重开
- 开启采样预览时，主界面的 DWM/GPU 预览会临时隐藏，避免两种预览叠在一起导致“间隔看起来没变化”
- 采样预览的 `Tk PhotoImage` 输入已从 `PPM data` 改为 `PNG data`，规避“抓帧成功但 Tk 无法解析图像”的问题
- 预览区支持**点击反推坐标**：点击画面任意一点，会自动计算目标窗口中的实际坐标
- 如果当前显示的是客户区，点击后会直接回填到 Debug 的 `X / Y`
- 如果当前显示的是完整窗口，点击标题栏/边框时会提示“该点不在客户区内”
- 点击预览后会显示十字准星，方便连续校准位置；该标记约 5 秒后会自动消失
- 命中客户区时，会自动把 `TARGET_X / TARGET_Y` 复制到剪贴板

### 后台运行模式
- 新增「转后台保活」按钮：将目标窗口停靠到屏幕边缘，仅保留极小可见角，保持**非最小化**状态
- 新增「强制窗口化」按钮：尝试把目标进程的顶层窗口改成普通窗口样式，便于后续移动
- 新增「设置分辨率」按钮：可把当前锚定窗口的**客户区尺寸**手动调整到「目标分辨率」里填写的宽高，默认 `800x600`，例如需要在 `800x600` 下截取模板图时使用
- 点击「执行脚本」时会自动把当前锚定窗口的**客户区尺寸**调整为 `800x600`，已是该尺寸时不改动窗口；这一步固定使用 `800x600`，不读取「目标分辨率」输入框
- 自动调整时若窗口处于后台保活位置或已最小化，会按新尺寸重新停靠到保活位置；调整失败则不启动脚本
- 新增「任务栏图标: 隐藏/显示」切换按钮：修改窗口 `EXSTYLE`，尝试切换任务栏按钮显示状态
- 新增「恢复原位」按钮：把窗口恢复到原始位置/状态
- 关闭本工具时也会自动尝试恢复目标窗口原位、窗口样式与任务栏图标状态，避免忘记手动点「恢复原位」
- 这一模式专门用于规避“游戏最小化后暂停渲染/暂停 UI 逻辑”的问题
- 对游戏而言，**不要再手动最小化**；应优先使用后台运行模式
- 当前实现会尝试停靠**同进程的所有顶层窗口**，并在日志中输出移动前后矩形
- 之所以不再完全移出屏幕，是因为部分游戏在“完全离屏/完全遮挡”后会停止渲染，导致实时预览冻结
- 如果停靠后仍然没有进入保活位置，通常说明该游戏是**独占全屏**或**自管理窗口**，标准 Win32 移动无效
- 如果 `转后台保活` 无效，可先点击 `强制窗口化` 再重试
- 任务栏图标切换通常会同时影响 Alt+Tab 可见性，具体效果取决于目标程序窗口类型

### Debug 放大镜
- 输入坐标 (X, Y) 和区域大小，放大查看指定位置的像素级细节
- 使用 DWM `rcSource` 裁切，GPU 渲染 6 倍放大
- 用于精确确认点击坐标
- 新增 `Debug 点击` 按钮：直接对当前 Debug 坐标执行一次普通后台点击
- 新增 `强力点击回退` 按钮：对当前 Debug 坐标执行更强的保底点击（先后台，再短暂前台硬件回退）
- 脚本和 Debug 触发的虚拟点击，现在会在预览窗口里短暂闪出坐标标记，便于对照后台点击是否打在预期位置

### 自动化脚本 (`script_action.py`)
- 提供以后台消息为主的自动化方法，适合在 `run()` 中顺序编排动作
- 内置诊断功能，检测管理员权限、窗口类名、子窗口结构等
- 默认会先确保窗口处于“非最小化”的后台运行状态，再尝试点击
- `script_action.py` 已整理为 `WindowAutomation` 调用风格，适合顺序编排大量动作
- 主界面的「执行脚本」当前会热重载并执行 `game_logic.py`；`script_action.py` 作为底层动作库被复用
- 模板识别现在会缓存已加载模板，降低长时间轮询时的重复读盘、重复解码和内存抖动
- 主界面支持勾选功能块；只有勾选的功能块才会在 `game_logic.py` 中执行
- 主界面新增 `抓鬼任务` 功能块；抓鬼统一先走地图直达长安城钟馗，附加选项 `自定义抓几轮鬼` 勾选后可填写轮数（未勾选为不限）
- 勾选的功能块按界面顺序依次执行；支持直跑的任务会直接进入对应模块，不再先走任务界面模板识别，当前包括 `挖宝图`、`秘境降妖`、`抓鬼任务`、`继续抓鬼`、`副本`；其余任务逐个交给活动界面调度
- `宝图` 为一个合并功能块：先通过活动界面执行打宝图，再直接执行挖宝图；活动界面找不到打宝图（例如当天已完成）时跳过，继续挖宝图
- 打宝图点击「听听无妨」后，会轮询右下角战斗取消按钮：从点击后开始计时，每次检测到取消按钮都重新计时，连续 30 秒检测不到即判定打宝图结束，开始挖宝图
- 挖宝图途中判断“正在战斗”的取消按钮阈值为 `0.78`，避免战斗中识别不到而提前判定“没有宝图了”

- `秘境降妖` 依赖 `templates/107MiJingXiangyao/` 下的 `jm_mjxy`、`jm_mjxy_tj`、`jm_mjxy_yyl`、`mjxy_jr`、`mjxy_jxtz`，战斗取消按钮复用 `templates/201ZhuaGui/quxiao.png`（阈值 `0.78`）
- `秘境降妖` 中途找不到继续挑战（战斗时间不计入，等 30 秒）或点击后 30 秒内没进入战斗时，会记录原因并结束本模块，此时不会点击离开秘境
- `抓鬼任务` 已接入基础流程，依赖 `templates/201ZhuaGui/` 下的 `jm_zgrw`、`jm_jxzg_qd`、`quxiao`

- `副本` 支持 5 个副本（蹈海去、金蝉心、琉璃碎、二重影、绿烟如梦），每天会扫描当天可做的 2 个副本并依次执行
- `副本` 识别使用 11 张模板：5 张活动界面入口图标 + 5 张副本选择界面副本名称 + 1 张 NPC 对话框「选择副本」按钮，全部放在 `templates/202FuBen/` 下（命名参考 `jm_daohaiqu.png / jm_fbxz_daohaiqu.png / jm_xuanze_fuben.png` 等），战斗取消按钮复用 `templates/201ZhuaGui/quxiao.png`

- `tasks/shared_rects.py` 维护任务共用矩形范围，例如 `HUODONG_SEARCH_RECT`、`BAG_SEARCH_RANGE`、`CANCEL_BUTTON_RECT`
- 主界面新增「终止脚本」按钮：采用协作式终止，收到请求后会在当前步骤结束点安全退出

- `drag()` 现在支持 `duration_sec`，用于控制从 A 到 B 的总拖动时长；默认约 `1.0` 秒
- 模板图默认放在 `templates/` 目录；可直接传文件名如 `start_button` / `start_button.png`

### 模板识别
- 已直接接入 `OpenCV` 模板匹配，适合“按钮样式固定，但位置不固定”的场景
- 默认在**整个客户区**内查找模板，不要求按钮在固定区域
- 现在支持 `search_rect=(left, top, right, bottom)`，可把搜索范围限制在指定客户区矩形内
- `find_image("start_button")`：返回模板中心点与匹配分数
- `find_image("start_button", search_rect=(402, 159, 717, 469))`：只在指定矩形框内找图
- `wait_image("start_button", timeout_sec=5)`：等待模板出现
- `click_image("start_button")`：识别后普通点击
- `click_image_robust("start_button")`：识别后强力点击回退
- 默认模板目录为 `templates/`，支持 `.png/.jpg/.jpeg/.bmp/.webp`
- 模板读取已兼容 Windows 中文路径目录，例如 `templates/BTRW/`

### 输入动作

| # | 动作 | 后台？ | 原理 | 适用场景 |
|---|---|---|---|---|
| 1 | `click()` / `double_click()` / `right_click()` | 完全后台 | 单一 `SendMessage` 鼠标消息链 | 普通点击、双击、右键 |
| 2 | `move_to()` | 完全后台 | 发送 `WM_MOUSEMOVE` | 悬停、预热鼠标位置 |
| 3 | `click_robust()` | 先后台后前台保底 | 先走后台点击，再临时前台化做一次硬件级点击 | 普通点击不吃的软件 |
| 4 | `find_image()` / `wait_image()` | 完全后台 | OpenCV 模板匹配 | 固定按钮、固定 UI、位置不固定 |
| 5 | `click_image()` / `click_image_robust()` | 识别后点击 | 模板匹配 + 点击链路 | 识别后自动点击 |
| 6 | `drag()` | 完全后台 | `SendMessage` 拖拽消息链 | 列表拖动、滑动条、拖拽操作 |
| 7 | `key_down()` / `key_up()` / `press_key()` | 完全后台 | 键盘消息链 | 回车、方向键、功能键等 |
| 8 | `hotkey()` / `send_text()` | 完全后台 | 组合键与 `WM_CHAR` 文本输入 | 快捷键、输入框文本填充 |
| 9 | `子窗口自动映射` | 完全后台 | 自动把主窗口客户区坐标映射到覆盖该点的子窗口 | UI 落在子窗口的场景 |

> 说明：鼠标点击类动作现在只保留一套 `SendMessage` 链路，避免重复发三套消息；如果你已经验证当前游戏这套能吃，脚本会更干净也更容易维护。

### 诊断功能
- 自动检测脚本/目标进程的管理员权限是否匹配
- 枚举窗口类名、客户区大小、子窗口结构
- 输出窗口是否最小化、是否已处于屏幕外后台运行状态
- `转后台运行` / `强制窗口化` 会输出关键 Win32 API 的返回值和 `GetLastError`
- 诊断输出显示在 GUI 日志区域
- 日志面板会自动裁剪旧日志，只保留最近一段内容，避免长时间运行后内存持续上涨

### 当前推荐使用方式
1. 先看标题栏权限状态；如果是普通权限，先点击「管理员重启」
2. 锚定目标窗口
3. 如果目标像独占全屏游戏，先点击「强制窗口化」
4. 如需在 `800x600` 下截取模板图，可在「目标分辨率」填入宽高（默认 `800x600`）后点击「设置分辨率」；只执行脚本时可跳过这一步
5. 点击「转后台保活」，让窗口保持非最小化并停靠到屏幕边缘
6. 如果你不需要主预览太高频，可先把「主预览间隔」设为 `0.5 / 1 / 2` 秒
7. 如果 DWM 预览仍冻结，先设置采样间隔，再点击「开启采样预览」
8. 直接点击预览画面反推坐标；命中客户区后会显示准星并自动复制 `TARGET_X / TARGET_Y`
9. 勾选本次要执行的功能块，例如「宝图」或「抓鬼任务」；`副本` 建议手动组好队再勾
10. 点击「执行脚本」：会先自动把目标窗口客户区调整为 `800x600`（已是该尺寸则跳过），再热重载并执行 `game_logic.py`
11. 如果本次只勾选支持直跑的任务，会直接执行对应逻辑，不依赖 `templates/RWJM/` 下的任务界面入口模板
12. `抓鬼任务` 会先走地图直达长安城钟馗，再进入抓鬼轮询逻辑；如勾选 `自定义抓几轮鬼`，抓满填写的轮数后停止
13. 跑 `宝图`、`秘境降妖`、`抓鬼任务`、`副本` 时，仍需准备各自模板目录下的素材；其中打宝图依赖活动界面模板 `000RenWuJieMian/jm_bt`、`jm_bt_tj`、`jm_canjia`
14. 如需中途停止，点击「终止脚本」
15. 在 `game_logic.py` 中编排游戏流程，在 `script_action.py` 中补通用动作和识别能力
